# music-app

This repo is about learning on how to take iTUnes API to make a music player

Currently, it has these features :
- Play/pause
- Song search
- Currently playing (hasn't been successful)

Improvements :
- Storing songs into an queue so previous and next song can be implemented
- Adding unit tests
